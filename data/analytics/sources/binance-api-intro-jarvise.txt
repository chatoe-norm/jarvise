- WebSocket Streams — out of scope
- FIX APIs — out of scope
- SBE — out of scope

Authentication and security (Binance intro → Jarvise)
-----------------------------------------------------
Binance supports HMAC signing, RSA/Ed25519, and session auth for some WS/FIX flows.
Jarvise today:
- Public market data: no API key (GET /api/v3/klines)
- Planned private read (P3): HMAC-SHA256 + X-MBX-APIKEY for GET /api/v3/account only
- Never create or use keys with withdrawal / transfer permissions
- Never call place/manage/cancel order endpoints
- Do not wire Binance Agent REST / MCP / order-capable agent tools into Jarvise

Rate limits and reliability
---------------------------
Binance enforces request weights and endpoint limits; excess → throttle/ban.
Jarvise integrations must: respect weights, use backoff, avoid hot loops on /analytics
page load (one sync per request is enough), monitor errors without logging secrets.

Environments
------------
Binance: Production, Testnet (where supported), Demo (product-specific).
Jarvise paper phase:
- Live public market data from production REST for paper analytics (OHLC)
- Venue testnets are optional and NOT required for paper ledger / analytics
- Signed balance read (P3), when shipped, uses env BINANCE_API_KEY/SECRET;
  soft-fail hide UI panel if keys missing

Agent Native (reference only)
-----------------------------
Binance publishes llms.txt, Agent REST API, and an MCP server for agent tooling.
Jarvise may READ documentation (llms.txt / intro / spot REST) for doctrine RAG.
Jarvise must NOT enable Binance MCP or Agent REST for order placement or live trading.
The docs site renders client-side: fetch llms.txt or the page's .md variant
(e.g. /en/docs/introduction.md), not the HTML URL.
Binance Skills Hub (agent skills marketplace): see binance-skills-hub-jarvise.txt.
Jarvise uses only a read-only public subset via skill jarvise-binance-intel.

Jarvise ALLOWLIST
-----------------
- GET /api/v3/klines — paper OHLC ingest (jarvise_ingest)
- GET /api/v3/account — planned P3 read-only spot balances (jarvise_exchange design)
- Fetch/RAG of official docs URLs on the Jarvise allowlist

Jarvise DENYLIST
----------------
- Place, manage, or cancel orders (any product)
- Withdraw / transfer / universal transfer endpoints
- Futures / margin / options trading APIs
- WebSocket user-data trading streams for execution
- FIX / SBE trading workflows
- API keys with withdrawal or transfer permission
- Binance Agent Native MCP/REST used to place trades
