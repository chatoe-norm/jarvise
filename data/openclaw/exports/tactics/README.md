# OpenClaw Tactical Intelligence & Post-Mortem Exports

This directory holds structured tactical notes and trade post-mortems generated by OpenClaw research agents.

## Sync Pipeline
- Markdown notes placed in this directory (`data/openclaw/exports/**/*.md`) are synchronized into Qdrant collection `jarvise_doctrine` via:
  ```bash
  jarvise rag sync-openclaw
  ```
- Once indexed into `jarvise_doctrine`, these tactical rules are retrieved during the second-layer review by Claude Sonnet (`auto_decide.py`) before approving or deferring trade candidates.

## Note Schema Standard
Each tactical file should follow this structure:
```markdown
# [Tactical Title] e.g. Post-Mortem: EMA20 Overextension Caution

- **Category**: Post-Mortem | Microstructure | Regime
- **Asset**: BTCUSDT / ETHUSDT / General
- **Date**: YYYY-MM-DD
- **Target Setup**: Pullback / Breakout

### Observed Failure Pattern / Market Inefficiency
[Describe the empirical pattern where trades failed, e.g. entry when price was >2.5x ATR away from 20 EMA with declining 4h volume]

### Actionable Rule (กฎการเทรด)
- ห้ามเปิด Long หากราคาขยายตัวเกิน 2.0x ATR จากแนวรับ EMA20 ให้รอจังหวะ Re-test หรือปฏิเสธราคาด้วยไส้เทียนก่อน
- ตรวจสอบ Volume Confirm: หาก Volume ratio < 0.8x ให้ Defer หรือ Reject คำสั่งทันที
```
