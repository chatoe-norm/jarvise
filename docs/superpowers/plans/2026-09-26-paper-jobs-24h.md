# Paper Jobs 24/7 (Enqueue + Expire) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Schedule paper enqueue and approval expire on the VPS via n8n → `jobs:8090`, with Redis status keys and `/analytics` Pipeline visibility — still no live orders and no `--auto-fill`.

**Architecture:** Extend `src/jarvise/jobs.py` with two subprocess runners (mirror ingest/rag). Publish Redis JSON to `jarvise:paper:last` and `jarvise:paper:expire:last`. Add two n8n workflow JSON files (4h run / 1h expire). Extend `/analytics` Pipeline + `/api/status`. Pass `JARVISE_PAPER_UNIVERSE` / `JARVISE_PAPER_TIMEFRAME` into the jobs container.

**Tech Stack:** Python 3.11+ stdlib `http.server` jobs API, Redis, n8n schedule + HTTP Request nodes, FastAPI web, pytest.

**Spec:** [docs/superpowers/specs/2026-09-26-paper-jobs-24h-design.md](../specs/2026-09-26-paper-jobs-24h-design.md)

## Global Constraints

- PAPER ONLY — no exchange order/trade/cancel/withdraw APIs.
- `paper-run` must **never** pass `--auto-fill` (enqueue only).
- Kill-switch engaged → exit code 3, HTTP **409**, Redis skipped payload.
- Env defaults: `JARVISE_PAPER_UNIVERSE=paper_core`, `JARVISE_PAPER_TIMEFRAME=4h`.
- Redis keys: `jarvise:paper:last`, `jarvise:paper:expire:last` via `publish_redis_status`.
- Cadence: n8n every **4 hours** (run), every **1 hour** (expire).
- Commit only when the user asks; plan commit steps are for the implementing agent when authorized.

```python
def run_paper_run() -> tuple[int, dict[str, Any]]:
    if kill_switch_engaged():
        payload = _skipped()
        publish_redis_status("jarvise:paper:last", payload)
        return 3, payload
    universe = os.environ.get("JARVISE_PAPER_UNIVERSE") or "paper_core"
    timeframe = os.environ.get("JARVISE_PAPER_TIMEFRAME") or "4h"
    cmd = [
        sys.executable,
        "-m",
        "jarvise",
        "paper",
        "run",
        "--universe",
        universe,
        "--timeframe",
        timeframe,
        "--json",
    ]
    proc = subprocess.run(cmd, capture_output=True, text=True, check=False)
    payload = _parse_stdout(proc)
    payload["paper_only"] = True
    payload["exit_code"] = proc.returncode
    publish_redis_status("jarvise:paper:last", payload)
    return proc.returncode, payload


def run_paper_expire() -> tuple[int, dict[str, Any]]:
    if kill_switch_engaged():
        payload = _skipped()
        publish_redis_status("jarvise:paper:expire:last", payload)
        return 3, payload
    cmd = [sys.executable, "-m", "jarvise", "paper", "expire", "--json"]
    proc = subprocess.run(cmd, capture_output=True, text=True, check=False)
    payload = _parse_stdout(proc)
    payload["paper_only"] = True
    payload["exit_code"] = proc.returncode
    publish_redis_status("jarvise:paper:expire:last", payload)
    return proc.returncode, payload
```
